# 🏫 LỚP HỌC HẠNH PHÚC - HỆ SINH THÁI QUẢN LÝ LỚP HỌC TOÀN DIỆN

> **Ứng dụng quản trị lớp học thông minh, tích điểm thi đua, điểm danh đa chiều, sơ đồ lớp học, trợ lý AI và trò chơi tương tác sôi động dành cho giáo viên và học sinh.**

---

## ✨ Tính Năng Nổi Bật (16 Phân Hệ)

- 🎯 **Tích Điểm & Đổi Quà**: Tích lũy xu hoa điểm tốt, vinh danh học sinh, cửa hàng đổi quà sáng tạo.
- 🎡 **Vòng Quay May Mắn & Cuộn Phim**: Gọi tên ngẫu nhiên, hộp quà bí ẩn, nhiệm vụ phi thuyền.
- 📋 **Điểm Danh Đa Năng**: Điểm danh nhanh, điểm danh theo tiết, thống kê tỷ lệ chuyên cần trực quan.
- 🤖 **Trợ Lý AI Đố Vui & Khởi Động**: Tự động sinh bộ câu hỏi khởi động theo môn học, chế độ Đấu Trường Fullscreen hoành tráng.
- 🔗 **Quản Lý Liên Kết**: Lưu trữ thời khóa biểu, tài liệu môn học, đính kèm logo và sắp xếp thứ tự linh hoạt.
- ⏱️ **Đồng Hồ Đếm Ngược**: Giao diện đếm ngược tập trung, tinh gọn, âm thanh báo hiệu sinh động.
- 📊 **Infographic & Báo Cáo**: Xuất báo cáo điểm danh, bảng vàng vinh danh dạng hình ảnh, PDF và Excel.
- 🪑 **Sơ Đồ Lớp Học 3D**: Bố trí chỗ ngồi trực quan, kéo thả dễ dàng.
- 🔊 **Máy Đo Tiếng Ồn**: Giám sát mức độ ồn của lớp học bằng micro thời gian thực.
- ☁️ **Đồng Bộ Dữ Liệu 3 Lớp**: Supabase Cloud ➡️ Local JSON Server ➡️ LocalStorage, an toàn tuyệt đối.

---

## 🛠️ Công Nghệ Sử Dụng

- **Frontend**: React 19, TypeScript, Tailwind CSS, Vite
- **UI & Animation**: Lucide Icons, Canvas Confetti, Motion
- **Dữ Liệu & Backend**: Local JSON Database, Supabase Client, Express Server
- **Trí Tuệ Nhân Tạo**: Google Gemini API

---

## 🚀 Cài Đặt & Chạy Cục Bộ

1. Cài đặt các gói phụ thuộc:
   ```bash
   npm install
   ```

2. Cấu hình biến môi trường (tùy chọn):
   - Tạo file `.env` từ `.env.example`
   - Nhập `GEMINI_API_KEY` nếu muốn sử dụng Trợ lý AI

3. Khởi động ứng dụng:
   ```bash
   npm run dev
   ```
   Ứng dụng sẽ chạy tại: `http://localhost:3000` (hoặc port được hiển thị).
